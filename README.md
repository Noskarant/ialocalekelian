# Atelier IA — Kélian

Application Windows locale (Tauri) pour chat Ollama, images ComfyUI et montage vidéo Whisper + FFmpeg.

**Dépôt public sans données personnelles, modèles IA ou fichiers multimédias.** Les dépendances et modèles sont téléchargés sur le PC de l'utilisateur.

La compilation Windows est déclenchée une seule fois sur `main` après l'ajout du code et peut aussi être lancée manuellement. Le dépôt est public : les runners standard GitHub Actions ne consomment pas le quota de minutes des dépôts privés.

Le fonctionnement réel du GPU et des modèles doit être validé sur Windows RTX 4060 8 Go avant de considérer la version prête pour une utilisation quotidienne.
